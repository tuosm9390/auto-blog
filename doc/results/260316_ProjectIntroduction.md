# [Project] Synapso.dev — 코딩은 당신이, 기록은 AI가.

## 1. 인사의 글

안녕하세요. 개발자의 생산성을 극대화하기 위한 도구를 만드는 **Synapso(시냅소)** 팀입니다. 코드를 짜는 시간만큼이나 그 과정을 기록하고 공유하는 것이 중요한 시대입니다. 하지만 우리는 늘 시간에 쫓기고, '기록'은 '개발'의 우선순위에 밀려 뒷전이 되곤 합니다. 우리는 이 문제를 해결하고자 합니다.

## 2. 설계 및 시작 배경

"왜 훌륭한 엔지니어들의 코드는 깃허브(GitHub)에만 잠들어 있는가?"
Synapso.dev는 이 질문에서 시작되었습니다. 수많은 개발자가 매일 혁신적인 코드를 작성하고 커밋(Commit)하지만, 그 이면에 담긴 고민과 해결 과정은 문서화되지 않은 채 잊혀집니다.

기존의 블로그 작성 방식은 개발 흐름을 끊고 별도의 에너지를 소모하게 만듭니다. 우리는 개발자가 평소처럼 **'커밋'하는 행위 자체가 곧 '기록'으로 이어지는 심리스(Seamless)한 워크플로우**를 꿈꿨습니다. 단순한 요약이 아닌, 코드의 맥락을 이해하는 시니어 엔지니어의 시각을 AI로 구현해보고자 이번 프로젝트를 기획하게 되었습니다.

## 3. 프로젝트 특징 및 차별점

Synapso.dev는 단순한 AI 글쓰기 도구가 아닙니다. 개발자의 문법을 이해하는 **'엔지니어링 파트너'**입니다.

- **GitHub Native 분석**: 단순한 텍스트 변환이 아닙니다. Git Diff를 실시간으로 분석하여 코드 변경의 '의도(Intent)', '맥락(Context)', 그리고 '영향(Impact)'을 깊이 있게 파악합니다.
- **시니어 엔지니어의 관점**: Google Gemini 2.5의 강력한 추론 능력을 활용하여, 마치 시니어 개발자가 코드 리뷰를 하듯 기술적인 통찰이 담긴 포스트를 구성합니다.
- **자동화의 극의(Auto-Posting)**: 크론(Cron) 기반의 자동 모드를 설정하면, 당신이 푸시(Push)하는 순간 AI가 백그라운드에서 분석을 시작하고 발행 대기 상태로 만들어줍니다.
- **Zero Data Retention**: 개발자의 자산인 코드를 소중히 다룹니다. AI 학습에 코드를 활용하지 않으며, 분석 후 즉시 휘발되는 보안 원칙을 준수합니다.
- **SEO & 성능 최적화**: Next.js 15와 ISR 기술을 통해 생성된 블로그는 검색 엔진에 최적화되며, 독자들에게 번개처럼 빠른 읽기 경험을 제공합니다.

## 4. 프로젝트 비전

우리의 비전은 명확합니다. **"모든 엔지니어가 자신의 영향력을 손쉽게 기록하고 공유하는 세상"**입니다.
Synapso.dev는 단순한 자동 블로그 서비스를 넘어, 개발자의 성장 궤적을 가장 정확하게 기록하는 아카이브이자, 기술 생태계의 지식 공유 문턱을 낮추는 가교가 될 것입니다. 우리는 기술 블로그 작성이 더 이상 '숙제'가 아닌 '보상'이 되는 경험을 제공할 것입니다.

## 5. 초기 테스터 모집 안내

현재 Synapso.dev는 핵심 기능을 완성하고 실제 사용자분들의 소중한 피드백을 기다리고 있습니다.

- **모집 대상**: 정기적으로 GitHub에 커밋하며, 기술 블로그 운영에 어려움을 겪고 있는 모든 개발자
- **테스터 혜택**:
  - 베타 기간 동안 **Business 플랜(무제한 생성)** 무료 제공
  - 서비스 정식 런칭 시 '초기 기여자(Early Contributor)' 뱃지 및 구독 할인권 증정
  - 최신 Gemini 2.5 Pro 모델 우선 접근 권한
- **참여 방법**: [Synapso.dev](https://synapso.dev) 접속 후 GitHub 로그인 -> '테스터 신청' 버튼 클릭
