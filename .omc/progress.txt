## 보안 패치 (Architect Advisory 반영)

### app/api/demo/generate/route.ts — JWT 서명 비교 timingSafeEqual 적용
- 변경: `import { createHmac } from "crypto"` → `import { createHmac, timingSafeEqual } from "crypto"`
- 변경: `if (expected !== sigB64) return null;`
        → `if (!timingSafeEqual(Buffer.from(expected), Buffer.from(sigB64))) return null;`
- 이유: 문자열 `!==` 비교는 early-exit으로 타이밍 차이 발생 가능 → timing attack 취약점
- 결과: Architect LOW advisory 해결 완료
